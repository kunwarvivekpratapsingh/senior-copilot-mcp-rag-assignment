## What is deliberately uncovered

Three areas account for most of the missing 11%, and each is a decision rather than an
oversight:

**`rag/ingestion/cli.py` — 0%.** The CLI is argument parsing plus calls into
`load_corpus`, `chunk_corpus`, and `build_index`, all of which are covered directly. A
test here would assert that `argparse` works. It is exercised for real on every container
start and in the compose smoke test.

**`telemetry.py` — 51%, `alarm_mcp/logging.py` — 43%.** Logging *configuration* —
processor chains, renderer selection, log-level mapping. The parts that carry a
correctness requirement, the redaction processor and the context processor, are covered;
what is not covered is structlog being wired up, which the first log line in any
integration test proves anyway.

**Per-tool wrappers in `alarm_mcp/server.py` — 78%.** Fourteen tools, each a few lines
of "call the connector, wrap the result". The tools used by the acceptance scenario and
the error paths are covered; a handful of the analytical tools are exercised through the
generated tool catalog rather than through an assertion.

## Reproducing

```bash
make coverage          # terminal summary + htmlcov/
```

The suite needs no running services: the simulator, both MCP servers, and the document
index are all constructed in-process.
